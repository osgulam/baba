    עבודה חדשה

    תמונות וסרטוןאפשר להוסיף כמה תמונות מזוויות שונות, וגם סרטון קצר (עד 40MB, בערך דקה). הפריט הראשון יוצג בגלריה; לחיצה על פריט אחר תהפוך אותו לראשי.

    כניסה לעריכה

    רק מי שיש לו מפתח גישה ל־GitHub של האתר יכול להוסיף ולערוך עבודות. את המפתח מדביקים פעם אחת בכל מכשיר.

    1. ב־GitHub: Settings ← Developer settings ← Fine-grained tokens ← Generate new token
    2. תחת Repository access בוחרים רק את המאגר של האתר.
    3. תחת Permissions: Contents: Read and write
    4. מעתיקים את המפתח ומדביקים כאן.
